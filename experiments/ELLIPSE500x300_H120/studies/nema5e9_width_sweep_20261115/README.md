## 固定项与科学改动

复用正式1669255的真实NEMA观测：总双能gamma发射量5e9（不是5e9次225Ac衰变），218/440初级计数分别1469053733/3530946267；原20视角、483743条440 Compton选中事件、原SC计数、每视角原行号与顺序全部固定。生产代码不抽取随机数，不重新能量展宽、不重新筛选、不新做输运。

以每个候选位置/材料/散射角对应的原连续材料分布为基础，令其物理截断后的原均值为μ、潜在转移能量为T：

`E_model(alpha) = mu + alpha*(T-mu) + alpha*epsilon_electronics + alpha*epsilon_position`

电子学方差仍按原T计算后乘alpha²；位置项同样乘alpha²，材料概率质量不变。于是原材料平均偏差保持，三部分标准差统一缩放，方差变为原来的1、0.64、0.36。该定义是**改变响应模型的科学对照**，不是重新模拟更好的探测器。观测仍含原来的噪声；缩窄不必改善结果。

100%直接调用原冻结v5函数。80%/60%使用上述均值保持的条件混合分布；原KN项、SC矩阵B、完整圆域每事件归一化、原q≤3 legacy选择以及ellipse_fraction保持。不是简单把旧角度sigma乘系数。

每个新模型使用原独立circle_train的170247条冻结校准事件、1e9个440初级gamma、原完整体积和20角旋转平均重算自己的S。100%复用已严格交付的原S。**绝不使用NEMA观测C的转置乘全1替代S，也不把80%/60%与旧S混用。**
