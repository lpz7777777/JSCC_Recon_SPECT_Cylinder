# 水 NEMA 单光子散射修正第二轮

复用上一轮严格交付的四套 20 视角 Geant4 观测。5e9 和 5e10 表示两能量合计发射的 gamma 数。每套观测各做 440 和 218 keV 一条新分支。已完成的 AC only 和两种原能窗分支提供同数据对照。

## 衰减

用均匀水腔的源点到晶体中心射线计算体内路径长度，乘以发射能量对应的总衰减系数。440→218 串窗使用 440 keV 的总衰减系数。几何、单元体积、视角曝光和匹配 S 沿用原方法。原代表点的完整 A/C 加权误差上界低于 2%。水衰减系数来自 [NIST 液态水总衰减表](https://physics.nist.gov/PhysRefData/XrayMassCoef/ComTab/water.html)。

正式作业内用已知活度做主窗、侧窗和串窗前投影对照，分别记录含水衰减和无水衰减算子的计数，再与目标 Geant4 非体内散射标签比较。投影真值由 3 mm 活度真值采样到原柱坐标网格，按实际 gamma 数归一。该审计同时包含网格近似及原探头响应的误差。主窗 A/C 的增益系数保持冻结。

## 固定散射模型

同一探头的另一档剂量作为独立蒙卡供体，种子区间独立。按发射能量分别统计 Geant4 标签中的体内散射和混合计数。投影模板只在真实晶体的同一探头面及材料层内作空间合并，视角方向使用周期边界。带宽由供体数据的双向 Poisson thinning 验证选定，各面及材料层的散射总量守恒。

以目标观测的 440 下侧窗拟合 440 发射量的相对比例，再固定其在 218 双侧窗的贡献，用两个窗总计数的 Poisson 似然拟合 218 比例。按这两个比例合成各主窗的固定散射背景。目标的体内散射标签在模板冻结后用于 QA。迭代中固定背景，不由当前重建反复更新。218 的原探头串窗背景由本分支同探头同剂量的最终 440 图生成。

这一轮比较的是已知水 NEMA 活度布局下，用独立输运建立的散射模型。剂量间留出检验覆盖统计波动，同一体模的空间分布仍是建模先验。EHE 小计数组即便总量准确，逐晶体逐视角的散射误差仍明显。
