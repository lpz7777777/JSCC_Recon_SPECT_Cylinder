本次使用同一H60双能三维球体真值和真空源、20视角、200个独立worker×2500万初级gamma，共5e9；产额0.114/0.259。新种子31100101–31100300。能量份额由产额乘对应真值积分决定，预期218份额约29.38078%，并非仅对两个产额归一。诊断计数按真实初级能量分解218/440两个窗，不改变原随机抽样或能窗判定。

两者使用原120mm全范围、78920个完整柱坐标活动单元与gamma/mm³密度。EHE生成自己的A218、A440、C440→218完整矩阵和灵敏度，PE-v4/Scatter方法保留。440→218只使用Scatter跨窗输出；不将PE光电峰结果误当跨窗响应。

完整输入validation10通过后，440单光子从全1初值运行200次；以本次440最终图预测固定加性串窗背景，再运行218单光子200次。两个阶段每10次原子/fsync保存active/full/manifest，共40检查点。第三路按同迭代两能量gamma密度求和，共三路各20帧；不表示Ac225活度。

主图比较双方50/100/150/200次的218、440和双能结果，另附JSCC2000/10000次。真实H60三维真值、既有ROI、固定发射源密度尺度、crop0、无平滑、轴/冠/矢及中央72mm MIP。EHE218背景来自440单光子200次；复用JSCC第200次218图的背景来自440单光子10000次，必须披露背景估计预算差异。
