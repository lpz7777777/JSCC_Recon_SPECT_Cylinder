## 1. 边界密度绑定的精确定义

800个极小相交单元与同层最近的完整内部单元共享密度，参数数由82040降为81240；所有相交单元的物理位置、响应、有效体积仍参与前向和灵敏度。没有删除边界、给小单元补零或将积分值当作密度。

令P将独立密度展开到活动网格，H为原活动列响应。组更新等价于在 `H P` 上做MLEM：

`u_g(new) = Σ_{j∈g} x_j × backprojection_j / Σ_{j∈g} sensitivity_j`，随后所有组内单元取同一密度。

初始化为统一密度；通过显式小矩阵H P的独立对照验证等价性。该组只减少极小横向边界单元的自由度；z端层没有全部绑定，因此不能预先保证它会消除所有轴向尖峰。

## 2. MAP目标与物理邻接

对每个分量固定归一化：观测计数总数C，`α=C/Σs`，`u=x/α`。单光子C是对应能窗实测计数；Compton C是筛选事件数；联合C是440单光子计数加筛选事件数。218的C包含固定串窗背景在内的该能窗计数；α只作为固定尺度，不作为真实背景估计。

最小化非负密度下的 `L(x)/C + λR(u)`，L为对应Poisson/扩展列表似然的负对数。原始强度x、观测、敏感度和440→218加性背景都不在每次迭代中重新归一化。

空间图有 **253029条实际共享面的邻接边**，覆盖径向、周期角向和z方向；跨径向环的不同角度划分按真实扇区交集连接。使用共享面在椭圆内的面积，外部不添加固定零邻居，不跨FOV边界拉向零。

每条边中心距离d、有效共享面积A，参考长度h=3mm，FOV体积V：

`R(u) = Σ (A·d/V) × ρ(h·(u_i−u_j)/d)`。

Huber：`ρ(t)=t²/(2δ)`（|t|≤δ），否则`|t|−δ/2`。小差异作二次约束，大差异作线性约束，降低尖峰同时允许较强边界。

TV：`ρ(t)=|t|`。本实现是**三维物理面图上的各向异性TV**，不是笛卡尔体素各向同性TV；可能出现块状/阶梯效应，报告中会明确。尺度和体积权重避免直接对非均匀极坐标网格做普通像素滤波。

## 3. 更新及数值边界

先做全局响应反投影，随后在rank0仅应用一次正则；更新密度广播到全部rank，避免每张卡重复加先验或先验随GPU数变化。

MAP采用非负Poisson EM加权KL代理函数加空间惩罚的M步，以带对角预条件的原始/对偶迭代求解。保留代理函数不高于原点的最佳可行解，再验证实际归一化似然加先验目标；**不是MLEM后做高斯平滑，也没有密度截顶。** 每步内迭代最多80次、对偶间隙容差1e−6，记录达到上限的次数和间隙。内迭代截断时应解释为下降检查的广义EM，不能宣称每个M步或最终MAP都已精确收敛。

参考方法：[De Pierro的MAP-EM研究](https://pubmed.ncbi.nlm.nih.gov/18215817/)及[EM-TV重建研究](https://link.springer.com/article/10.1007/s11075-023-01517-w)。本项目的归一化、共享面图、KL子问题和分布式实现是为此实验设计的具体实现，应由本地/集群测试证据评估，论文不能代替项目正确性验证。

`optimization.json`保存各分量C/α、目标历史、最大目标增长、最大代理函数增长、最大内层对偶间隙和内迭代上限计数。允许实际归一化目标数值增长上限2e−5，代理增长上限1e−10；超过时失败并停止依赖链。λ=0在小问题上须回归到原MLEM。
