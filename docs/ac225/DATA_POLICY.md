# 数据、冻结文件与Git交付

| 文件层次 | 存放/处理 |
|---|---|
| 源码、配置、解析几何、宏生成器 | 保持现有导入/执行路径，Git保存小型文本 |
| 合同、作业登记、独立验收、SHA收据 | 保留原证据路径和字节；新研究独立命名 |
| generated运行目录 | 本地/超算保存；Git忽略，不移动活跃依赖 |
| 系统矩阵、响应缓存、事件数组、完整图像历史 | 本轮不加入Git，不复制到导航目录 |
| 图形工程 | scripts、几何参数、小型CSV/JSON和说明进入Git；PNG/PDF/SVG及NPZ保留本地 |
| 旧说明时间线 | 原字节归档到history；当前入口不再叠加互相矛盾的“最新”段落 |
| SSH/账号凭据 | 工程外，永不提交 |

只读索引的`local_data`和`figures`是数据位置，不承诺克隆仓库即可获得这些大文件。图形工件SHA可保留对本地图片/数据的引用；复现需相应已验收结果。新增PNG/PDF/SVG不随本轮推送，既有Git历史媒体保持不动。

本轮新增提交按UTF-8小文本、单文件最多1MiB审核；禁止矩阵、原始/模型数组、事件列表、压缩归档、可执行二进制和敏感凭据。已被Git跟踪的历史大文件不因本轮整理重写历史。

Git只推送本轮明确审核的源码、参数、说明和小型证据。发布前检查暂存路径、内容类型、大小、敏感模式和引用；科学源/作业登记的前后SHA以及原说明快照见[整理审计](../organization/20261019/README.md)。
