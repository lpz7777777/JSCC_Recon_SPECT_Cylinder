Use interior ROIs and native weighted activity as primary comparisons

Global query NRMSE is a grid-transfer diagnostic, not the primary physical comparison. At tiny-fraction outer cells, large native concentrations can carry little support-weighted activity. Corrected-data projection diagnostics

Original-truth total response errors: A218 +0.582%, A440 -1.696%, C440to218 +0.125%. Disjoint16x8mm detector-bin spatial L2 errors: A218 26.90%, A440 22.08%, C440to218 17.47%. Unfitted projection-centroid RMSE: A218 2.882mm, A440 1.901mm, C440to218 3.515mm. These values are computed from corrected source-tagged observations; raw sparse-bin and pooled metrics are separate.

Absolute total agreement does not certify spatial response. Finite MC kernel statistics, depth interpolation, phase averaging, unmeasured tails and finite-camera edges remain physical-model limitations. This comparison changes platform, response and grid together and cannot establish a single framework cause.

Maximum four-phase total-efficiency sample CV: A218 8.46%, A440 5.56%, C440to218 8.19%. Variation includes MC counting noise and hole/crystal phase; it is not a pure shift-invariance test.

Original vacuum acquisition: 440-to-218 cross-window response arises in the detector/collimator, not body scatter. Each reconstruction uses its own final440 to form the fixed218 background; its change cannot be attributed solely to the C kernel.

Two actual MC acquisitions, correct old/new angular bookkeeping: 218keV: L2 10.706%, independent-Poisson noise benchmark 10.998%; 440keV: L2 14.354%, independent-Poisson noise benchmark 15.813%.
