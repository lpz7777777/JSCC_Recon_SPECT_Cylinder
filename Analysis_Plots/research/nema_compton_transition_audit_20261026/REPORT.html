角点数变化的过渡带，与体积归一化是否有关？

应把“角点数突变引起的离散误差”作为重点候选，但当前未发现简单的漏乘、重复乘体积或S体积约定错误。体积权重正确，并不能保证用中心点代表有限单元时，响应积分误差在20→40→60→80角点的交界处连续。

本次新增了精确边界对齐、全网格体积公式核对、调用实际冻结核与MLEM更新函数的等价单元分裂检查，以及过渡带附近的有界K-only积分计算。没有改动生产代码、原始结果、匹配S或事件选择，没有提交超算任务。此报告补充此前的Compton环纹研究报告，不覆盖旧报告。

2. 不等体积格子应怎样归一化？

当前未知量ρⱼ是每单位体积的源强密度。一个格子的总源强是ρⱼΔVⱼ。均匀体模中，大格子和小格子的ρ应相同，总源强则随格子体积变化。不能要求不同体积的格子包含相同总源强，也不能在显示ρ时再除一次体积。

非中心圆盘的单元体积为：

ΔVⱼ = ½[(r+3)²−(r−3)²] × (2π/nθ) × 3 = 36πr/nθ mm³。

全网格保存体积与解析公式一致，各圈角扇区完整覆盖对应圆环，径向单元连续，完整圆柱总体积与π×255²×120一致。单格体积在角点数增加处下降是合理的；整圈体积没有因为格子变多而凭空倍增或减少。

当前实际响应链条可写成：

Bⱼ = A(xⱼ) ΔVⱼ
wᵢⱼ = Kᵢ(xⱼ) Bⱼ
Qᵢⱼ = wᵢⱼ / Σₖ wᵢₖ = Kᵢ(xⱼ)A(xⱼ)ΔVⱼ / Σₖ[Kᵢ(xₖ)A(xₖ)ΔVₖ]。

这里K包括当前康普顿方向、能量与KN因子，A对应被选第一探测通道的权重。归一化分母是带单元体积的和，不是对不等体积格点做等权求和。虽然Compton函数里没有再显式乘一次ΔV，但输入B在矩阵转换阶段已经含有它。额外补乘会造成重复。

匹配S由同一归一化响应Q作用于均匀校准事件生成，采用完整支持体积和实际校准发射数的系数，再作视角平均。当前并没有把每个体素的列单独归一到相同S，也没有在Compton阶段给每个半径环强行相同权重。

ρⱼ(new) = ρⱼ / Sⱼ × Σᵢ [Qᵢⱼ / (ΣₖQᵢₖρₖ)]。

将Qᵢⱼ写为ΔVⱼhᵢⱼ、Sⱼ写为ΔVⱼsⱼ，可以看到更新分子和S中的同一个ΔVⱼ相消，而预测计数分母仍正确保留各格子的体积。因此“S里面有体积，所以S不该再用于相除”这一推断不成立；它正是密度变量与积分响应相匹配所需的约定。

等价分裂代数检查：取8个实际冻结事件和过渡带附近48个控制位置，调用正式使用的核与更新函数。把42、78、114 mm的12个控制单元各复制成两个相同代表位置的半体积单元，B和S各减半，输入密度保持一致。48列变成60列后，子响应之和与父响应一致，三种正密度输入的一步更新最大相对差为2.34×10⁻⁷。故意保留未减半的父S，子单元密度立即错误地变为正确值的0.5倍。

这是一项等价表示的代数检查，不是新物理重建：A设为每单位体积常量以隔离体积因子；使用保存的正S值作控制；子单元代表坐标相同，没有模拟真实移动后的子中心。它说明实际核归一化与更新函数能够保持体积记账一致，不证明真实A×K在有限单元内的积分足够准确。

4. 体积正确，为何过渡处仍可能出现问题？

实际算法用格子中心的A、K乘体积近似整个格子内部积分。角点数改变时，格子的切向宽度和形状突然变化，中心近似的误差也可能突然改变。当前K的位置展宽来自探测晶体的不确定性；它不是对源格子内部的积分，不会自动根据20/40/60个角点的单元宽度做完整源单元平均。

此外，固定20视角下，每圈n个点会形成n/20个旋转相位组：20、40、60、80点分别对应1、2、3、4组。过渡处不仅格子体积变了，未知量个数、角向表示能力、响应列的相关结构也变了。这些差异不会仅靠乘对体积而消失，可能与后期无正则MLEM的误差放大耦合；当前尚未计算全算子的谱或完成改变网格的因果对照。

6. 对下一步研究重点的调整

这次线索将“角点数过渡处的响应离散一致性”提高为优先研究对象。比先旋转整张网格更直接的下一步，是针对三条过渡带检验：同一片连续空间，采用粗扇区或细扇区表示时，逐事件A×K积分之和是否一致，以及匹配S是否保持同样的一致性。

需要明确分开两步：第一步是相同代表点的等价分裂（本次已经做，检查记账）；第二步是真实子单元的不同中心或积分（本次没有完成，检查物理与采样近似）。后者才可能确定过渡处是否是实际环纹的重要来源。应同时检查校准事件和成像事件的残差模式，不直接根据重建图像改S，不一并修改网格、物理核、正则和视角数。

当前结论是：体积与归一化的代数约定一致；过渡带离散误差仍然可疑，而且比“少乘一个体积”更符合目前证据。不应把代码一致性扩大成“Compton响应完全正确”，也不应把边界关联扩大成“已确定根因”。
